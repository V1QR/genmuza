# Игровой API

После загрузки студии доступен `window.GenMuza`. Воспроизведение требует первого пользовательского жеста из-за правил браузера.

```js
// Выполняйте play внутри обработчика клика.
await GenMuza.play();
await GenMuza.setState('combat');
await GenMuza.setIntensity(85);
await GenMuza.trigger('victory');
GenMuza.updateGame({ risk: 0.7, health: 0.4, enemies: 6 });
const project = GenMuza.getProject();
GenMuza.loadProject(project);
await GenMuza.exportProject('wav');
GenMuza.stop();
```

Состояния: `exploration` 25%, `tension` 50%, `combat` 75%, `boss` 100%. `setIntensity` принимает конечное число 0–100. `updateGame` принимает risk/health 0–1 и enemies 0–20. Опасность рассчитывается из риска, потери здоровья и числа врагов; повторные входы объединяются в интервале 350 ms. Автоматическая UI-симуляция включается отдельным переключателем.

События: `safe` — один светлый колокол, `hit` — низкий синтезированный удар, `victory` — разрешение из текущего лада и переход к исследованию. `play` и переходы возвращают Promise; новое состояние выбирается после рендера, а фактически вступает на музыкальной границе. Имена неизвестных состояний и нечисловые входы отклоняются.

## Встраивание в браузерную игру

Встраивающая страница и студия должны иметь один origin. Принимаются только сообщения родительского окна с совпадающим origin. Произвольные внешние страницы управлять студией не могут.

```js
const frame = document.querySelector('iframe');
frame.contentWindow.postMessage({
  type: 'genmuza', action: 'state', value: 'combat'
}, location.origin);
```

Действия: `state`, `intensity`, `game`, `event`. Автоматический старт из postMessage не включён: первый клик производится внутри студии. Game Kit содержит `genmuza-bridge.mjs`, который оформляет этот контракт в класс.

## Unity / Godot

Эта версия не запускает браузерный DSP непосредственно внутри нативного Unity / Godot. Для них предоставляется набор экспортированных аудиослоёв и инструкция синхронного воспроизведения. Нативный плагин не тестировался и не включён.

Для адаптации на уровне всего состояния экспортируйте один проект в четырёх интенсивностях с одинаковыми BPM, seed и длиной. Запустите соответствующие WAV одновременно и меняйте громкость состояний по тактам. Для управления отдельными ролями используйте stems. Экспорт при интенсивности 100% даёт все события; более низкая интенсивность уменьшает плотность внутри дорожек. Громкостью stem нельзя в точности заменить фильтрацию отдельных событий, поэтому для точного состояния нужны его отдельные рендеры.

Unity: синхронно планируйте AudioSource по одному DSP time, включите loop и сохраняйте исходную относительную громкость файлов. Godot: синхронизируйте слои с аудиовременем и используйте циклические WAV; переключения делайте на границе 4 × 60 / BPM секунд. Эти шаги описывают интеграционный контракт; конкретная настройка зависит от версии и устройства.
